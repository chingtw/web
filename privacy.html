隱私權政策

最後更新日期：2026 年 8 月 19 日

CHING x（以下簡稱「本服務」）重視您的隱私。本政策說明我們如何收集、使用及保護您的個人資訊。

1. 資料收集

本服務可能收集以下資訊：

  • Google 帳戶資訊：當您授權本服務時，我們會取得您的 Google 帳戶電子郵件地址，用於身份識別。
  • Google 試算表資料：本服務會存取您授權的 Google 試算表內容，以提供筆記同步與管理功能。
  • 使用紀錄：基本的 API 呼叫紀錄（時間、動作類型），用於除錯與改善服務品質。

2. 資料使用方式

我們收集的資料僅用於以下目的：

  • 提供並維護本服務的核心功能
  • 處理您的 API 請求
  • 改善服務品質與修復錯誤
  • 與您聯繫有關服務的重要通知

⚠️ 我們不會將您的資料出售、出租或分享給任何第三方用於行銷目的。

3. Google API 服務使用揭露

本服務使用 Google API 服務，並遵守 Google API 服務使用者資料政策，包括有限使用要求（Limited Use requirements）。

具體而言：

  • 本服務僅在提供或改善面向使用者的功能時，才會存取 Google 使用者資料。
  • 不會將 Google 使用者資料傳輸給第三方，除非為提供服務所必需、取得使用者明確同意，或因法律要求。
  • 不會將 Google 使用者資料用於投放廣告。
  • 不允許人工讀取 Google 使用者資料，除非取得使用者明確同意、出於安全目的、遵守法律要求，或資料經過匿名化處理。

4. 資料儲存與安全

我們採取合理的安全措施來保護您的資料：

  • 所有資料傳輸均透過 HTTPS 加密
  • OAuth 2.0 Token 安全儲存，不以明文形式保存
  • 定期檢視存取權限與安全設定
  • 存取範圍限制在服務運作所需的最小權限

5. 資料保留

我們在提供服務所需的期間內保留您的資料。您可以隨時透過以下方式撤銷存取權限：

  • 前往 Google 帳戶權限設定 撤銷本服務的存取權
  • 直接聯繫我們要求刪除資料

6. Cookie 與追蹤技術

本服務目前不使用 Cookie 或其他追蹤技術來追蹤使用者行為。如未來有變更，將更新本政策並通知使用者。

7. 兒童隱私

本服務不針對 13 歲以下的兒童。我們不會故意收集 13 歲以下兒童的個人資訊。

8. 政策變更

我們可能會不定期更新本隱私權政策。變更時，我們將更新本頁頂部的「最後更新日期」。建議您定期查看本政策以瞭解最新資訊。
